# Índice de Manuales — GGTO (Fase 5)

Documentación completa del sistema GGTO (CANTV C.A., Central Francisco Salias).

- **Manuales técnicos** (`RepoTecnico/Manuales/`): fieles al código real, con
  referencias `ruta:línea`, para el equipo de desarrollo y operación.
- **Manuales literales** (`docs/Manuales/`): el mismo árbol, en lenguaje sencillo,
  para técnicos de campo, supervisores y administradores.
- **Imágenes** (`docs/imagenes/`): diagramas e infografías (SVG + PNG).
- **PDF descargables** (`docs/Manuales/pdf/`): versión imprimible de cada manual.
- **Ayuda en la plataforma**: sección **AYUDA** de la SPA (`/ayuda`).

## 3. Cómo regenerar

```bash
cd docs/Manuales/_build
python3 generar.py            # Markdown -> HTML estilizado
node exportar_pdf.mjs         # HTML -> PDF (Playwright/Chromium)
python3 verificar_pdf.py      # comprueba páginas, índice y anclas
./sincronizar_manual.sh       # copia HTML/PDF/imágenes a app/web/public/manual
cd ../../../app/web && npm run build
```

El índice de la sección AYUDA (`app/web/src/pages/Ayuda.tsx`) se deriva de los
encabezados de `docs/Manuales/**`; si se agregan o renombran manuales hay que
regenerarlo.
