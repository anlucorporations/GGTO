concideraciones_ODN.md

0. cada ODN (columna A) posee una o Varios OLT.
1. cada OLT (columna B) posee hasta 17 Tarjetas (columna C).
2. cada Tarjeta puede tener 4, 8 o 16 Puertos (Columna D) de forma correlativas. el estandar es 16 Puertos
3. cada Puerto puede tener asociado Distintos tipos de FAT (columna F) segun:
3.1. si Segundo Nivel (Columna E) es 1:16 el puerto contiene hasta 4 FAT asociadas (preferentemente correlativos).
3.2. si Segundo Nivel (Columna E) es 1:8 el puerto contiene hasta 8 FAT asociadas (preferentemente correlativos).
3.3. si Segundo Nivel (Columna E) es 1:32 el puerto contiene hasta 2 FAT asociadas (preferentemente correlativos).
3.4. si Segundo Nivel (Columna E) es 1:64 el puerto contiene hasta 1 FAT asociadas (preferentemente correlativos).
4. el maximo de Inmuebles (Columna G) asociado a un FAT depende de su 2do Nivel (Columna E).
5. cada FAT posee caracteristicas obligatorias como Latitud (Columna I), Longitud  (Columna J); caracteristicas complementarias como Observaciones  (Columna N), Estatus (columna L), ASF (Columna O); caracteristicas de Servicios (segun el texto que posee el la Columna Inmueble) como Puertos Vendidos o Puertos Disponibles .
6. una Dirección (Columna H) puede estar asociados a Varios FAT.
6.1. una Dirección puede contener Varios inmuebles.
6.2. el texto del Inmueble puede describir el Tipo (Quinta, Casa, Recidencia, Edificio, Centro Comercial, Etc.), la Distribucion (segun el tipo contiene Pisos que a su vez contienen Apartamentos, Locales o Anexos).
6.3 el Inmueble puede estar Disponible o Vendido.
