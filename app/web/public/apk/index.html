Cómo instalarla

  1. Abra el archivo descargado ggto-tecnico.apk desde las notificaciones o el gestor de archivos.
  2. Si Android lo solicita, permita «Instalar aplicaciones desconocidas» para el navegador o el gestor de archivos.
  3. Confirme la instalación y abra GGTO Técnico.
  4. En el primer arranque se muestra el aviso de uso restringido: debe aceptarlo para continuar.
Verificación del archivo: compare el hash SHA-256 con el publicado en apk.json. Si no coincide, no instale el archivo.

Si la descarga no comienza automáticamente, use el botón «Descargar la APK».
